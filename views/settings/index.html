MCAI 设置

模型 API 填在 AstrBot 模型页；在这里选择模型、测试能力和管理 MC 主机。

连接 MC 主机

模型与能力

排障与审核均使用 AstrBot 的 OpenAI 兼容 Chat／Responses 提供商。两种搜索可同时启用，审核独立进行。

会产生少量模型与搜索请求。不会执行 MC 操作，也不会发送群消息。执行进度汇报需 Responses commentary；要求简短中文，推理摘要不转发。未观察到汇报不等于不支持。

群与管理员

默认 400。单条回复超过此值时发成一张合集卡片。

高级设置

服务端

只填服务端目录，在独立窗口运行 mcai tm，再执行 .\start.bat。自动重启循环保留。运行中的启动配置变更将在空闲后生效。

主机

PowerShell、存档 Java 与内存额度修改后需重启 B（托管窗口继续运行）。B 不访问外部网站；MOD 搜索、下载与构建在 A 完成。

诊断导出

导出用户插件命令、模型请求与响应、执行进度汇报、审核、工具结果和消息记录。包含未成功创建任务的命令；B 离线也可导出本地已保存内容。
