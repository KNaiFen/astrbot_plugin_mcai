A 端高级设置

测试会发送少量模型与搜索请求，不执行 MC 操作或发群消息。执行进度汇报需 Responses commentary，默认关闭；未观察到汇报不等于不支持。

模型用量与费用保护

按货币、输入、输出、缓存的顺序填写；留空只显示 token。费用为按已返回用量计算的估算。

群与通知

管理群内权限、回复形式和故障提醒。

每行指定一个实例及通知群；留空只在 B 主机保存故障现场。

默认 400。单条回复超过此值时发成一张合集卡片。

服务端

管理正式服、试服配置和每个实例的故障留证开关。

新实例可以只填写配置名和服务端目录。托管窗口仍使用原来的 start.bat；运行中的启动配置变更会等待空闲。

B 主机

适用于这台主机上的所有服务端。

PowerShell、存档 Java 与内存额度修改后需重启 B；托管窗口可继续运行。

主动留证

对已经开启留证的正式服生效；通知群在「群与通知」中配置。

窗口内观测到 3 次启动失败时留证。留空恢复默认值（120 秒、256 MiB）。

保存后立即生效。超过容量时按时间清理最早的整起事故，不影响任务记录和正式服备份。
