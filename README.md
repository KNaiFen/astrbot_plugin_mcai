# MCAI · MC 群内排障与运维助手

直接在 QQ 群里用聊天的方式管理你的 Minecraft Java 服务器。

人不在电脑前、没开远程桌面也没关系：玩家在群里喊卡或崩服，你只要回复一句，AI 就能自动帮你翻日志、查区块和模组、定位原因，并给出通俗易懂的处理方案；涉及改配置、动存档、装删 MOD 或重启时，先在群里发一份人话清单，等你点头确认后再自动停服备份执行。

[快速上手](#四步快速上手) · [用起来长什么样](#在群里用起来长什么样) · [常用群指令](#常用群指令) · [更多使用文档](#更多使用文档)

## 它能帮你做什么

- **排障不用连远程**：群里说一声哪台服卡了或起不来，或者直接引用玩家的报错消息，AI 会自己查日志、看配置、扫存档，用大白话告诉你问题出在哪。
- **日常杂事群里办**：查谁在线、看服务器状态和 TPS、发服内公告、改白名单、调配置、设定时备份或定时重启，手机上发条消息就搞定。
- **改东西有安全兜底**：只读查询 AI 自己完成；正式服涉及修改文件、存档、MOD 或发维护命令，必须先过一遍独立 AI 把关，再发一张简明的待批清单到群里，**管理员发短码同意后才会先停服备份再动手**，绝不背着你乱改乱删；测试服（独立测试服或任务隔离副本）则可在安全边界内免人工审批高效测试。
- **不改你原本的开服习惯**：继续用你原来的 `start.bat` 和控制台，不用换面板，也不用把 QQ 机器人电脑暴露到公网；控制程序重启不会把正在运行的 MC 服务器带崩。
- **越用越顺手**：问题修好验收后，会自动整理一份通俗的排查笔记存下来，下次再遇到类似毛病可以直接参考。

## 先认识三样东西

MCAI 由三部分组成，可以装在同一台 Windows 电脑上，也可以分别装在“机器人电脑”和“开服电脑”上：

| 组件 | 装在哪里 | 干什么用 |
|---|---|---|
| **A：AstrBot 插件** | 跑 QQ 机器人的 Windows 电脑 | 在 QQ 群里收发消息、驱动 AI 干活，也是全部设置的管理界面 |
| **B：MC 控制程序** | 跑 MC 服务器的 Windows 电脑 | 帮 AI 查看日志与存档、做备份、执行批准后的维护操作 |
| **托管窗口** | MC 服务器电脑（每个服开一个） | 一个普通命令行窗口，你在里面照常运行原来的 `start.bat` |

数据由 A 主动加密连向 B，机器人所在电脑不需要公网端口。

## 下载与环境要求

当前版本为 **0.22.2**，A、B 和托管窗口请保持同一版本（协议 `mcai-9`）。见 [0.22.2 下载与校验和](https://github.com/KNaiFen/astrbot_plugin_mcai/releases/tag/v0.22.2)及[更新日志](docs/usage/releases.md)。

- **A 插件包**：`astrbot_plugin_mcai.zip`（也可以直接在 AstrBot 插件页填仓库地址安装）
- **B 主机包**：`mcai_windows_host.zip`（里面自带可选的服内诊断探针 Probe 0.5.0）

**你需要提前准备（仅支持 Windows 10 1809+ / Windows 11）：**

- **Python 3.12+** 与 **PowerShell 7.3+**（注意是新版的 PowerShell 7，不是系统自带的蓝框 PowerShell 5.1）
- **机器人电脑（A）**：已装好 **AstrBot v4.29.4+** 并连上 QQ 群，配好 OpenAI 兼容的模型 API
- **开服电脑（B）**：装一个 **Java 21+** 给存档工具使用（你原本 MC 用的 Java 8 / 17 照旧保留在 `start.bat` 里，两套 Java 互不影响）

> 已有旧版本想升级？先看[升级步骤](docs/usage/operations.md#升级步骤)，升级不会覆盖你原来的配置和自定义规则。

## 四步快速上手

下面是最快跑通的开箱流程；如果需要跨公网连接、配多台服、或者看每个配置项的详细说明，直接看[完整部署指南](docs/usage/install.md)。

### 第 1 步：在开服电脑装好并启动 B

把 `mcai_windows_host.zip` 解压到例如 `D:\MCAI`，打开 **PowerShell 7** 依次执行：

```powershell
Set-Location -LiteralPath 'D:\MCAI'
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
Copy-Item -LiteralPath '.\host.example.json' -Destination '.\host.json'
Copy-Item -LiteralPath '.\instances.example.json' -Destination '.\instances.json'
```

用记事本打开两个刚复制出来的配置文件：
- **`host.json`**：填一串自己随便生成的共享令牌 `token`（比如用 `.\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(32))"` 生成），再填好 PowerShell 7 和 Java 21 的路径。
- **`instances.json`**：把示例路径改成你真实包含 `start.bat` 的 MC 服务端目录，再简单写一句群里怎么称呼这台服（例如 `"CTI整合包服，群里叫CTI服"`）。

填完后启动 B，**这个窗口保持开着**：

```powershell
.\.venv\Scripts\python.exe -m mcai host
```

启动后窗口里会打印一串 64 位**证书指纹**，先复制存好，第 3 步要用。

### 第 2 步：在托管窗口里启动你原来的服务器

在开服电脑**再开一个 PowerShell 7 窗口**，打开托管环境并照常运行你的 `start.bat`（如果服务器原本开在普通窗口里，先正常停服再切进来）：

```powershell
& 'D:\MCAI\.venv\Scripts\mcai.exe' tm -C 'D:\MC\CTI'
# 看到提示符后，在这个窗口里像平时一样开服：
.\start.bat
```

### 第 3 步：在 AstrBot 装上插件并连起来

1. 打开 AstrBot 插件管理页，上传 `astrbot_plugin_mcai.zip`（或通过仓库地址安装）并启用，点进 **「MCAI 设置」**。
2. 在 **主机连接** 填好 B 地址（同机部署填 `https://127.0.0.1:18765`）、共享令牌和第 1 步复制的证书指纹，点 **测试连接** 通过后保存。
3. 在 **模型与能力** 选好你配在 AstrBot 里的排障模型和审核模型（可以选同一个，审核会独立运行），点 **保存并测试、自动配置**。
4. 在 **群与通知** 填好管理员 QQ 和允许使用的群号并保存，然后去群里发一句 `/mcaihelp`，收到帮助回复就大功告成了。

### 第 4 步：可选装上服内探针 Probe

想让 AI 直接看到**谁在哪、实时 TPS/MSPT、哪个区块或实体最卡**，只需停服后从 B 包的 `probe/` 目录挑对应 MC 版本和加载器（Fabric / Forge / NeoForge）的 **一个 JAR** 放进 `mods/` 即可，客户端不用装。详见[服内探针安装表](docs/usage/probe.md#安装)。

## 在群里用起来长什么样

- **随手查状态（不建任务，不耗模型）**
  > `/mcaiserver` 或 `/mcaiserver cti`
- **随口问一句服务器怎么了（只读问答，不改任何文件）**
  > `/mcaiask cti服现在稳不稳，刚才怎么突然掉 TPS 了？`
- **正式交办排查或日常维护（管理员发起）**
  > `/mcainew 主城卡顿 是CTI服，昨天更新模组后玩家在主城附近一走就卡`
  （也可以直接在 QQ 里**引用玩家吐槽的消息**，再发 `/mcainew 主城卡顿`。）
- **玩家随时补线索（普通群聊不会打扰任务）**
  > `/mcaisay 主城卡顿 我叫 Steve，坐标 120 65 -300，大概 20:10 开始卡`
  （同样支持附带或引用崩溃日志、压缩包和截图。）
- **看懂清单再点头，修好后验收归档（管理员）**
  > AI 查清后会在群里发待批清单和短码，核对没问题发 `/mcaiapply 主城卡顿 9F2A7C` 执行；如果觉得方案要改，不用批准，直接 `/mcaisay` 说怎么改就行。
  > 验证没问题后发 `/mcaidone 主城卡顿` 结束任务并自动整理经验笔记。

## 常用群指令

方括号 `[]` 表示可选内容，实际发送时不用打方括号；如果改过 AstrBot 唤醒前缀，把 `/` 换成你的前缀即可。

| 指令 | 谁能用 | 做什么 |
|---|---|---|
| `/mcaiserver [实例ID]` | 群成员 | 实时查看服务器在线状态、人数和 TPS（不消耗模型） |
| `/mcaiswitch 实例ID start\|stop\|restart\|forcestop\|forcerestart` | 管理员 | 直接开关或重启服务器（强制操作需二次确认） |
| `/mcaiask 问题` | 管理员（可开放群成员） | 单次只读问答，自动隐藏玩家 IP、密钥等隐私 |
| `/mcainew 任务名 [问题描述]` | 管理员 | 新建排障或运维任务，支持引用消息、附日志和截图 |
| `/mcaisay 任务名 内容` | 群成员 | 给正在进行的任务补充线索、日志或截图 |
| `/mcaisaymode 任务名 true\|false` | 管理员 | 临时禁止或恢复普通群成员往这个任务里发补充 |
| `/mcaistatus 任务名` | 群成员 | 看任务进度、用了多少 token 和估算费用 |
| `/mcailist [页码]` | 群成员 | 看本群现在有哪些正在进行中的任务 |
| `/mcaiplan 任务名` | 群成员 | 重新查看待批清单和短码，或看多轮维护进度 |
| `/mcaiapply 任务名 短码` | 管理员 | 批准执行当前待批清单 |
| `/mcaischedule list` | 群成员 | 查看定时备份和定时重启计划 |
| `/mcaischedule pause\|resume\|delete 编号` | 管理员 | 暂停、恢复或删除定时计划 |
| `/mcaipause 任务名` / `/mcairesume 任务名` | 管理员 | 暂停任务保存现场 / 继续排查 |
| `/mcaistop 任务名` | 管理员 | 放弃并中止任务，释放服务器占用 |
| `/mcaidone 任务名` | 管理员 | 验收完成，释放占用并在后台保存经验笔记 |
| `/mcaihelp` | 群成员 | 查看群指令帮助 |
