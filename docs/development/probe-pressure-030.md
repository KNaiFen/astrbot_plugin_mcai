# Probe 0.3.0压力验证数据

[开发索引](README.md) · [复现与环境](probe.md)

2026-11-15，Windows x64／Python3.12.14，Java17.0.21+9或21.0.7，固定五目标与spark1.10.37／1.10.53／1.10.109。两个主测实例并行，期间穿插隔离功能验证；冷启JIT、GC和同机负载造成明显波动，不能由本表推导固定开销比例，也不能把不同加载器／外部MOD的差异归因给Probe。

spark保持测试环境原有默认后台采样；前台限时命令按spark自身行为替换后台采样。因此spark列较低的数值不代表Probe提速。表内只比较当前隔离负载，不作为生产健康或修复验收门槛。

“请求”仅计采集期诊断请求，不包括窗口后30次ping和取消自检。“部分普查”只统计scan.partial；大NBT请求均按预期触发1MiB输出限制，整项省略而不截断SNBT。GC已按事件时间过滤到各自60秒窗口。全部有效非absent窗口通过running／取消监视≤2、scans／cancelled回落为0以及各历史集合上限检查。

126个有效采集窗口；每窗口预热30秒、采集60秒。主测两目标各54个窗口，其余三目标各6个最大档窗口。

数值为JFR一秒平均tick窗口均值的跨重复中位数，括号为重复间范围；P95也仅针对一秒窗口。CPU单位为MC进程CPU毫秒/墙钟秒，RSS为最大工作集MiB。GC为测量窗口内事件总数/累计毫秒。busy表示四并发普查上限拒绝。
