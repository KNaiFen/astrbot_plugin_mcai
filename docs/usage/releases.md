# 0.20.1 发布说明

0.20.1 继续使用 `mcai-9`。请按[升级步骤](operations.md#升级到-0201)配套更新 A、B 与托管窗口。Probe 仍为 0.5.0；如需本次改进，请停服后用新包中同名的 JAR 替换旧文件。下载及校验见 [GitHub Release v0.20.1](https://github.com/KNaiFen/astrbot_plugin_mcai/releases/tag/v0.20.1)。

| 模块 | 主要更新与修复 |
|---|---|
| 主机与群命令（`d977924`） | B 运行时窗口标题显示 `MCAI-HOST`，退出恢复原标题。群提示用引号分隔可复制命令；拼错、误加空格或漏写分隔时提示正确写法。排查提示引导用已有引用续读大结果，避免原样重查。 |
| 卡顿与 JVM 内存（`64623f4`） | Probe 提供全服／维度阶段计时、主线程 CPU 与 GC 停顿、内存池和近期回收数据，以及已加载实体的定向诊断。B 增加 JFR 内存摘要、类直方图和 HPROF 汇总；spark 仍可作为独立的采样来源。 |
| 模拟玩家（`5d4a721`） | 八个目标支持移动、传送、朝向、潜行和主手交互，返回小数位置与区块就绪状态。可选游戏模式、无敌和跳过原版玩家数据写入；已有同名数据时拒绝以临时模式创建。 |
| 区块归因与热点（`02b7a57`） | 提供已加载区块的计划刻积压和区块阶段独占墙钟榜，区分方块／流体计划刻、随机与区块 tick、刷怪及实体等类别。对象跨区仍按身份合并；采样达到容量上限时报告省略和淘汰。 |
| Mixin 兼容（`fceeff9`） | 区块阶段改用可组合的 MixinExtras 包装，Forge 1.16.5 使用明确的目标方法并限制在服务端主线程。已在八个安装目标及 CatServer 1.16.5 隔离服复核。 |

诊断参数、版本差异和模拟玩家命令见 [Probe 使用说明](probe.md)及[JVM 查询说明](queries.md)。

## 0.20.0 发布说明

0.20.0 使用 `mcai-9`。随 B 包提供的 Probe 标记为 0.5.0，包含高压开销优化及八目标模拟玩家通道修复。

| 模块 | 主要更新与修复 |
|---|---|
| Web 管理控制台 | B 端新增管理接口；A 端设置视图新增「任务看板」「经验知识库」「数据占用与清理」「作业与下载管理」及单选按项能力测试交互。 |
| 上下文架构与压缩 | 稳定主系统提示与工具前缀（动态时间信息移出系统提示），对 Responses 主请求、独立审核与审核反馈整理启用任务范围缓存键；实施 75% 软瘦身（SQLite 存根外置）与 85% 分批交接摘要两级压缩。 |
| 工具输出与知识检索 | 强化作业静态元数据去重、ANSI 清理、9,000／14,000 字符大结果外置与分页续读、日志异常聚类去重及大 NBT 分层展开；`mc_knowledge` 拆分为绑定时紧凑索引与按编号按需读取全文。 |
| 归档回填与审核容量 | `/mcaidone` 归档按主载荷优先合并作业连续 `output` 分块并按净预算回填近期 Tier-1 存根，保证精确数值进入总结请求与经验文档；独立审核前压缩过长反馈并保留原始 `tool_call` 证据，遇到 `context_length_exceeded` 时缩减证据视图而非放行或重放。 |
| 脚本审核提示 | 明确 `script_files` 始终相对于实例根目录解析、不随 `cwd` 变化；遗漏或误填子目录路径时提示正确的实例根目录相对路径并阻止原样重复失败。 |
| Probe 0.5.0 | 优化高压下的主线程与后台采样开销，补齐并验证 Forge 1.7.10／1.16.5／1.19.2／1.20.1／1.21.1、Fabric 1.20.1／1.21.1 与 NeoForge 1.21.1 共八个目标的模拟玩家网络通道。 |

## 0.19.1 修复记录

0.19.1 是维护版本，A、B 与托管窗口继续使用 `mcai-9`。从 0.18.0 或更旧版本升级时已要求配套更新，随 B 包提供的 Probe 仍标记 0.5.0。

| 编号 | 修复或说明 |
|---|---|
| AUD-01 | 跨盘恢复先按卷检查剩余空间，再校验候选并替换；替换失败时保留原目录和候选。 |
| AUD-02 | `scheduled_backup_dir` 省略、留空或只含空白时使用 `data_dir/backups`。 |
| AUD-03 | 在线备份从本次 `save-all flush` 对应的控制台游标之后查找完成回执。 |
| AUD-04 | 正式发布区分已准备和 B 已受理；断线先查原编号，只有证据充分才以原参数补交。 |
| AUD-05 | 托管命令发送、查单及退出等待有明确期限；到期保留原编号和未知状态。 |
| AUD-06 | 调度遇到暂时的 SQLite 错误会退避，持续故障会显示降级；一个实例的窗口等待不阻塞其他实例。 |
| AUD-07 | 收到通知即入发件箱并同时推进游标，一个群离线不会挡住其他群。 |
| AUD-08 | 日志只从行首识别时间；坏时间头标为未知，正文和堆栈不会中断查询。 |
| AUD-09 | 实例配置验证通过后再原子替换；留证容量保存后若应用失败，页面显示已保存值和运行上限。 |
| AUD-10 | Probe 在游戏主线程采集快照，历史统计在后台聚合，避免拖慢心跳和取消。 |
| AUD-11 | 另卷定时备份纳入磁盘空间告警，设置页单列目录占用；无法完整统计时提示单独监控。 |
| AUD-12 | 文档明确 A 在插件启动时校验 PowerShell 7.3+；启动行为保持不变。 |
| AUD-13 | 源码 ZIP 附带构建清单，无 Git 的解包目录也可构建；三个候选 ZIP 校验后才替换旧产物。 |
| AUD-14 | 工作区列表和文本支持续页，文本按字符边界读取，后台处理文件 I/O。 |
| AUD-15 | 点恢复优先复用已核实空闲的扇区，保留其他区块的原始字节。 |
| AUD-16 | 审核说明明确只比较 Java 路径和停服命令；比较逻辑不变。 |
| AUD-17 | 修正 Probe 检查脚本的断言格式，恢复 Ruff 格式检查。 |
| AUD-18 | 通知游标保存留证库标识及末事件，换库或发现游标超出高水位时重新读取留存事件。 |
